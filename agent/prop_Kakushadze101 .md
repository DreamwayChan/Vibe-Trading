## 提示词

```
请用Kakushadze 101 公式集做多因子选股并回测，严格按下面约束执行，不要自行扩大因子范围。

【股票池与区间】
- 标的池：A股人形机器人板块
- 研究/回测参考区间：2024-01-01 至 2026-07-23（若数据不足，用可得的最近区间并说明）
- 频率：日频（interval=1D）；预测目标：次日相对收益（截面）
- 引擎约定：本项目 config.json 没有生效的 rebalance_frequency 字段；调仓频率与退出规则必须写在 code/signal_engine.py 的日频权重序列里（某日权重=0 即当日退出）。禁止臆造或依赖 config.rebalance_frequency。

【只用这些因子（白名单）】
仅允许使用以下「存活」因子，禁止使用该库其余任何因子（包括失效、跳过）：
alpha101_042, alpha101_083, alpha101_057, alpha101_018, alpha101_054, alpha101_060, alpha101_025, alpha101_033, alpha101_053
【硬性禁止】
- 禁止使用「失效」因子
- 禁止把整库Kakushadze 101或按主题批量拉入
- 若某白名单因子算不出，跳过它并说明原因，不要用其他因子顶替

【合成与选股规则】
1. 对每个存活因子做截面标准化（或分位数打分），方向保持原定义（高分看多）
2. 等权合成综合分；若某日某因子缺失，在剩余有效因子上重新等权，不要填 0 硬凑
3. 每日按综合分从高到低选 Top 20 作为候选持仓（等权）
4. 输出：综合分 Top20 股票列表（代码、名称、综合分、各因子分）、以及相对基准的简要解读
5. 加入大盘择时过滤（指数 <MA20 时空仓）
6. 对反转类白名单因子在趋势市中降权（不要引入白名单外因子）

【持仓退出（硬性，必须写进 SignalEngine）】
仅「跌出 Top20」不够。对每只已持仓股票，每日先检查持仓期保护，再决定是否继续持有：
1. 峰值回撤止损：相对持仓期内最高收盘价回撤 ≥ 15% → 当日权重置 0
2. 止盈：相对成本涨幅 ≥ 35% → 当日权重置 0（可一次性清仓）
3. 时间止损：连续持仓 ≥ 30 个交易日仍未触发 1/2，且综合分排名较入选时恶化 ≥ 10 名 → 当日权重置 0
4. 选股退出：未触发 1–3，但当日跌出 Top20 → 当日权重置 0
5. 上述规则必须体现在每日信号序列中；回测后检查 artifacts：
   - by_exit_reason 不能几乎全是 end_of_backtest
   - 对大赢家（持仓期内峰值收益 > 20%）抽样说明是否被规则截断，避免「冲高后回到成本才卖」

【交付要求】
- 先列出最终实际使用的因子 ID（必须 ⊆ 白名单）
- 再给出选股结果表
- 回测后报告：total_return、sharpe、max_drawdown、trade_count、rebalance_count、by_exit_reason
- 用 3–5 条白话说明：这组因子大致在选什么风格、主要风险是什么、退出规则是否生效
- 明确声明：这是研究/回测结果，不是实盘买卖建议；未计入完整交易成本前，不作“可盈利”结论

```
